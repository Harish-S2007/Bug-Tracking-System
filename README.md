# Bug Tracking and Configuration Management System

## Introduction

Bug Tracking and Configuration Management System is a web-based
application designed to manage software bugs, configuration items,
change requests, versions and releases.

## Features

- User Login
- Dashboard
- Bug Reporting
- Bug Assignment
- Bug Status Tracking
- Change Request Management
- Configuration Item Management
- Version Management
- Release Management
- Git/GitHub Integration
- Jenkins CI/CD
- Automated Testing

## Technology Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- Flask

Database:
- SQLite

SCM Tools:
- Git
- GitHub
- Jenkins

Testing:
- PyTest
